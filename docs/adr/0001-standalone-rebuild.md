# ADR 0001：独立新仓重制，断代不迁移

- 状态：已接受
- 日期：2026-09-29

## 背景

BetterAIChat（原项目，main @ v0.27.4，约 17k 行 Kotlin）已定型，革命性演进受限于其架构：上帝 ViewModel、服务定位器耦合、三套消息模型、样板化工具系统、i18n 割裂。审计确认了 10+ 个用户可见 bug（记忆在 Anthropic/Gemini 丢失、Agent 切换不落库、清空上下文无效等）。

## 决策

1. 在独立新仓库（NovaBAIC，应用名 BetterAIChat2）中重制，**不继承原仓库的 git 历史、代码与数据**。
2. 原项目仅作**行为参考与能力清单**，实现全部重写；工具矩阵从 62 个瘦身到约 40 个并升级契约。
3. **断代**：不做旧数据迁移、不兼容旧数据库。applicationId 改为 `com.verlintas.baic2`，可与旧版并存安装。

## 后果

- 干净的地基与历史；无迁移技术债。
- 旧用户需重新配置（预期，产品决策）。
- 原项目后续可从新仓库反向借鉴模块与思路（单向反哺，不做双向同步）。
